# LocalLab tool audit — 2026-10-16

Read-only audit of the 10 tools plus the umbrella CLI. Nothing was changed in the tool repos. Bugs were reproduced with scratch scripts unless marked *(read only)*. Effort: S/M/L.

## Cross-cutting themes (fix once, benefits several tools)

1. **Real Claude Code JSONL is mishandled in 5 tools** (agent-checkpoint, transcript-to-test, toolcall-linter, tokenauditor, transcript-bridge): one record per content block with a repeated `message.id`, a leading `summary` line breaks sniffing, `isSidechain`/`isMeta` records are included, and linter looks only at top-level `tool_calls`. Share one tested reader or fixture set.
2. **Unknown or snapshot model names price at $0** in both agent-circuit-breaker and tokenauditor (single-segment suffix strip, 2024-only price table). Silent cap bypass and silent zero cost. Use longest-prefix match, warn, and fail closed.
3. **gzip handling** is broken in AgentVCR and agent-circuit-breaker (forwarded `Accept-Encoding`, decoded body, header copied back).
4. **Secrets**: tapes (AgentVCR), checkpoints, generated tests (`--scrub` leaks) and the bridges have no or weak redaction/auth. A shared `redact` pass is the top feature in 3 tools.
5. **Browser-reachable localhost servers** (toolcall-cache CORS `*`, mcp-openai-bridge text/plain POST) allow tool execution from any web page.

## umbrella `locallab` CLI *(read only)*

Bugs
- `pipeline.py:131-142`: only tokens that already exist are resolved against the recipe dir, so outputs such as `-o audit.json` are written to the CWD while `assert` files resolve against the recipe dir. The README recipe's asserts then fail. Fix: run steps with `cwd=output_dir` (create it; it is currently never created) and resolve `assert.file` there.
- `pipeline.py:226`, `_eval_jq`: a missing key raises an uncaught `KeyError`. A non-boolean result is reported as a failure with no hint. Catch and print `ASSERTION ERROR`.
- `cli.py:170`: missing PyYAML raises `RuntimeError` as a traceback. Catch in `main` and exit 2.
- Step `env:` values are not placeholder-expanded (global ones are).
- `versions` reports "not installed" for any tool whose `--version` fails, including installed tools without that flag.

Features: `locallab pipeline --keep-going`; `locallab doctor --json`; `locallab tapes` to run `agent-vcr diff`/`tokenauditor` across a dir; `locallab init` to scaffold a recipe.
