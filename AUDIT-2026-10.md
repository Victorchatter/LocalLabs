# LocalLab tool audit — 2026-10-09

Read-only audit of the umbrella package and all 10 tools (shallow clones of each repo, selfchecks run where possible).
Severity: **H** high, **M** medium, **L** low. "(run)" = reproduced; otherwise found by reading code. Nothing in the tool repos was modified; these are proposals.

## Cross-cutting themes (fix once, benefits many tools)

1. **Real Claude Code transcripts with a leading `{"type":"summary"}` line are rejected** (sniff checks only line 1): tokenauditor, agent-checkpoint, transcript-to-test. Claude Code also writes one JSONL record per content block sharing `message.id` — double-counts in tokenauditor, breaks pairing in transcript-to-test. Factor into one shared tape/transcript reader.
2. **Gzip corruption through proxies**: agentvcr (records lossy), agent-circuit-breaker, toolcall-cache all forward `Accept-Encoding` and mangle bodies. Strip `Accept-Encoding` upstream.
3. **Pricing table is stale and unknown models cost $0** (tokenauditor, agent-circuit-breaker) — budgets fail open. Share one price table, warn/refuse on unknown, longest-prefix match, cache read/write rates.
4. **Streaming usage** is mishandled in agentvcr (no usage recorded), circuit-breaker (7x overcount), tokenauditor (nothing parsed from SSE).
5. **Local HTTP servers lack Origin/Host/CSRF/auth checks**: mcp-openai-bridge, toolcall-cache.
6. **CI only runs `selfcheck.py`** everywhere; no pytest, negative tests, lint, Windows. Add a cross-tool CI test: record streamed tape → audit → lint → convert → generate test.
7. Suggested shared feature: `locallab tape validate|info` so tape-format drift is caught centrally.

## 1. locallab (umbrella)
Bugs
- H: packaged recipes fail YAML parse — unquoted `file: {output}/...` (`recipes/hydrate-replay.yaml:10`, `record-audit-lint.yaml:11,14`, README example). Quote them; catch `yaml.YAMLError` in `pipeline._load_recipe` → exit 2.
- H: `selfcheck.py:37` writes fake tools as `name.py`; on Linux/macOS `shutil.which` never finds them, so the check fails. Write extensionless executables on non-nt.
- M: `__version__` 0.1.0 vs pyproject 0.2.0 → use `importlib.metadata`.
- M: `tools.json` package for agent-checkpoint is `agent-checkpoint`; README/PyPI is `localab-checkpoint` → `update` targets wrong package.
- M: `install-all` clones from git (cli.py:67) while README says PyPI; never upgrades existing installs.
- M: jq evaluator (pipeline.py:48-117): operator inside string literal misparsed; uncaught KeyError/TypeError → traceback instead of assertion failure; missing key raises instead of null.
- M: unresolved `{agent_cmd}` placeholders are executed literally; no `--var`. Output dir never `mkdir`'d; `{input}`/output default into read-only site-packages.
- L: `hydrate-replay.yaml` jq-asserts a SQLite file; `_maybe_resolve_path` rewrites flag values that look like filenames; `doctor` FAILs on uninstalled tools (should SKIP; add `--strict`); `versions` conflates broken with missing; `_version_from_text` misses `v0.4.0`.
Features: `locallab run -- <agent cmd>` (record→audit→lint→test with cost cap); recipe `vars:`/`--var`, `assert: {exists,jq,grep}`, `if:`/`continue-on-error`; `doctor --json/--strict` + tape-schema compat matrix; `init`/`ci` scaffolding; `tape validate`.
